## Goal
On the PR Overview tab, the reviewer clicks **Generate brief** and gets a summary, **Risk areas** and **Review focus — read these first**. All of it comes from exactly one LLM request over facts computed beforehand. The brief is cached per PR against the head SHA. It shows which inputs it was built from and which were missing. A focus item opens Files changed at the cited line.
